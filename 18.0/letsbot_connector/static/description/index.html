How it works

Live in three steps

No API key to copy and paste. Odoo creates a dedicated key and hands it to LetsBot over a secure server-to-server call.

1
Install the app
Install LetsBot WhatsApp AI Inbox from the Odoo Apps menu, like any other module.
2
Connect to LetsBot
Open Settings → LetsBot WhatsApp and press Connect to LetsBot. Sign in (or create an account) and pick your workspace.
3
AI answers from Odoo
The first import starts, real-time updates switch on, and your AI agent and team can answer from Odoo data.

Security and data

Private by design

  • ✓Admin only. Only Settings administrators can connect, disconnect or change the integration.
  • ✓Dedicated key. Odoo creates a dedicated integration user and a standard Odoo API key for LetsBot. You can pick an existing user under Advanced.
  • ✓Signed webhooks. Every real-time update is signed with HMAC-SHA256.
  • ✓Minimal payload. A webhook carries only the record id, its last update time and its status. No customer data is pushed; LetsBot reads what it needs through the Odoo API with the permissions you control.
  • ✓Never slows Odoo down. Updates are queued in your transaction and sent by a scheduled action after commit, with automatic retries.
  • ✓Nothing sent before you connect. No data leaves Odoo until an administrator pairs the database. Disconnect revokes the key and stops all updates immediately.
FAQ

Questions, answered

Do I need a LetsBot account?
Yes. The app connects Odoo to the LetsBot service. During Connect to LetsBot you can sign in or create an account. The Odoo integration is included on every LetsBot plan, including the trial.
Is the app free?
Yes. The Odoo app is free and open source (LGPL-3). LetsBot itself is a subscription service, and WhatsApp messages are billed by Meta.
I use Odoo Online. Can I still use LetsBot?
Yes. Odoo Online does not allow third-party apps, so connect from LetsBot (Odoo → Connect) with your Odoo address, database, login and an API key. Odoo only allows API access on the Odoo Online Custom plan.
Will customers receive messages as soon as I connect?
No. Every customer notification starts off and nothing is sent during the first import. You turn each notification on after its WhatsApp template is approved by Meta.
Can the AI see other customers’ data?
No. Customers only ever see their own orders and invoices, and the AI never shares other customers’ data.
Does LetsBot change my Odoo data?
LetsBot only reads during sync. It writes to Odoo only when someone uses an action in the chat (for example, creating a lead or a quotation) or when the optional conversation summary is enabled.
Which languages are supported?
The app’s settings are translated into Arabic, Spanish and Portuguese. LetsBot’s dashboard, live chat and mobile apps are available in Arabic, English, Spanish and Portuguese, and the AI replies in the customer’s language.
Does the integration user count as a paid Odoo user?
The dedicated integration user is an internal user. On plans billed per user you can pick an existing user instead, under Advanced in the LetsBot settings.
What happens when I disconnect or uninstall?
Disconnect revokes the LetsBot API key and stops all webhooks immediately. You can uninstall the app afterwards like any other module.
